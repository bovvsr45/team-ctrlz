학교급이 오를수록
급식은 더 든든해지는가?

부산 학교급식 데이터로 검증한 초·중·고 칼로리 비교 연구

팀원: 박서찬 · 배여준 · 백은준 · 서동연

01문제 인식

"중학생이 되면, 고등학생이 되면 급식이 더 많아지고 든든해진다"는 이야기는 흔하다.

하지만 실제 칼로리·영양 수치로 확인된 적은 드물다.

교육부 NEIS 개방포털이 전국 모든 학교의 급식 메뉴·칼로리·영양성분을 인증키 없이 실시간으로 공개하고 있다는 것을 발견했다.

→ 부산 초·중·고 급식을 직접 숫자로 비교할 수 있는 기회.

02가설 (사전 등록)

주가설

학교급(초·중·고)이 높아질수록 점심 급식 평균 칼로리가 높을 것이다.

판정 기준: 초 < 중 < 고 순서 성립 + 초-고 평균 차이 200kcal 이상 → 지지

보조가설

주 후반(목·금)일수록 튀김·면류 메뉴가 더 많이 나올 것이다.

판정 기준: 목·금 평균 등장비율이 월~수 평균보다 높으면 → 지지

03데이터 및 방법

NEIS 학교기본정보 API
schoolInfo — 학교급·주소(구·군) 확인

NEIS 급식식단정보 API
mealServiceDietInfo — 일자별 메뉴·칼로리·9개 영양소

둘 다 open.neis.go.kr, 인증키 불필요, 실시간 JSON 응답

표본: 6개교 (초2·중2·고2, 서로 다른 6개 구·군)

기간: 2026년 5월 4주차 평일 5일 (중식만)

방법: 학교별 일일 칼로리 평균 → 학교급별 평균 비교, 메뉴 텍스트에서 튀김/면류 키워드 요일별 집계

04데이터 검증 — 환각 검문소

  • 경남고등학교 급식 데이터를 처음 조회했을 때 칼로리·급식인원이 다른 학교보다 이상하게 낮았다.
  • 원인 확인 결과, MMEAL_SC_CODE(급식구분) 파라미터를 지정하지 않아 조식(아침) 데이터가 섞여 들어온 것이었다.
  • MMEAL_SC_CODE=2(중식)로 재조회하여 올바른 점심 데이터로 수정했다.
모든 수치는 AI가 API를 직접 호출해 받은 JSON 원문 그대로이며, 추정치는 없다. 다만 표본이 6개교·5일뿐이라 "부산 전체"로 일반화하기엔 이르다는 한계를 그대로 기록했다.

07예상 밖의 발견

같은 고등학교끼리도 편차가 컸다:

학교평균 칼로리
건국고등학교832.3 kcal
경남고등학교1,147.5 kcal

차이 315.2kcal — 학교급(초-고) 간 차이(345.2kcal)에 맞먹는 크기다.

→ 학교급보다 학교별 급식 예산·운영 차이가 더 클 수 있다는 신호.

08결론 및 제언

학교급이 오를수록 급식 칼로리가 높아진다는 예상은 실제 데이터로 확인됐다 (초644.7 → 중829.5 → 고989.9kcal).

하지만 학교급 간 차이만큼이나 학교 간 편차도 컸다.

제언: 부산시교육청은 학교급별 급식 기준 칼로리뿐 아니라 학교 간 편차도 함께 점검할 필요가 있다.

09한계 및 향후 과제

  • 표본 6개교 · 5일치 — 부산 전체(초307·중172·고142개교)로 일반화하기엔 이른 규모
  • 중식(점심)만 분석 — 조식·석식은 미포함
  • 향후: 학교 수·기간을 늘려 표본 확대, 지역(구·군)별 비교 추가 가능
