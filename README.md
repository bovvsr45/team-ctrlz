# team-ctrlz

중2 DataAI 2기 · 부산정보영재교육원 · 팀 ctrl+z

## 연구 주제 (가제)

**학교급이 오를수록 급식은 더 든든해지는가 — 부산 학교급식 데이터 분석**

교육부 NEIS 개방포털(인증키 불필요)로 부산 초·중·고 학교급식의 실제 칼로리·영양성분·메뉴를 받아, 학교급에 따라 급식이 얼마나 달라지는지 데이터로 확인한다.

## 가설

- **주가설**: 학교급(초·중·고)이 높아질수록 점심 급식 평균 칼로리가 높을 것이다.
  - **판정 기준**: 표본 학교(학교급별 2곳, 평일 5일)의 평균 칼로리 순서가 초<중<고이고, 초-고 차이가 200kcal 이상이면 **지지**.
- **보조가설**: 주 후반(목·금)일수록 튀김·면류 메뉴가 더 많이 나올 것이다.
  - **판정 기준**: 요일별 튀김/면류 등장 학교 비율을 계산해 목·금 평균이 월~수 평균보다 높으면 **지지**.

## 연구 결과 요약 (실제 데이터로 계산 완료)

- **주가설 → 지지.** 표본 6개교 실측 평균 칼로리: 초 644.7kcal < 중 829.5kcal < 고 989.9kcal. 초-고 차이 345.2kcal(기준 200kcal 이상 충족).
- **보조가설 → 기각.** 목·금 평균 등장비율 50.0% vs 월~수 평균 51.1%로 거의 동일. 오히려 표본 중에서는 **수요일**이 6개교 전부(100%)로 가장 높았다 — 예상과 다른 결과를 그대로 기록.
- **흥미로운 발견**: 같은 고등학교끼리도 편차가 컸다(건국고 832kcal vs 경남고 1,148kcal, 차이 315kcal) — 학교급 차이보다 학교 간 차이가 더 클 수 있다는 신호.

전체 계산 과정과 원자료는 `data/raw/`, 전체 서술은 `report/`의 hwpx 보고서 참고.
