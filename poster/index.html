학교급이 오를수록
급식은 더 든든해지는가

팀원: 박서찬 · 배여준 · 백은준 · 서동연

탐구 동기 · 목적

"학교급이 올라가면 급식이 더 든든해진다"는 이야기를 실제 칼로리·영양 수치로 확인한다. 교육부 NEIS 개방포털은 전국 학교 급식 정보를 인증키 없이 실시간 공개하고 있어, 부산 초·중·고 급식을 직접 비교할 수 있었다.

가설

주가설 — 학교급(초·중·고)이 높아질수록 점심 급식 평균 칼로리가 높을 것이다.

판정 기준: 초<중<고 순서 성립 + 초-고 차이 200kcal 이상 → 지지

보조가설 — 주 후반(목·금)일수록 튀김·면류 메뉴가 더 많이 나올 것이다.

데이터 및 방법

  • NEIS 급식식단정보 API (open.neis.go.kr, 인증키 불필요)
  • NEIS 학교기본정보 API — 학교급·주소(구·군) 확인
  • 표본: 6개교(초2·중2·고2, 6개 서로 다른 구·군) × 평일 5일(2026.5)
  • 방법: 학교별 일일 칼로리 평균 → 학교급별 평균 비교, 메뉴 텍스트에서 튀김/면류 키워드 요일별 집계

결론 및 제언

학교급이 오를수록 급식 칼로리가 높아진다는 예상은 실제 데이터로 확인됐다(초644.7→중829.5→고989.9kcal). 그러나 같은 고등학교끼리도 편차(건국고 832 vs 경남고 1,148kcal)가 학교급 간 차이만큼 컸다 — 학교급보다 학교별 급식 예산·운영 차이가 더 클 수 있다는 신호다.

1
칼로리가 낮은 학교에 급식 예산 우선 지원
같은 학교급 안에서 평균이 낮은 학교부터 예산을 더 배분해 편차 줄이기
2
같은 학교급 안 '편차 큰 학교' 우선 점검
학교급 기준 충족 여부만이 아니라, 급 안에서 격차가 큰 학교를 먼저 진단
3
NEIS 공개 데이터로 상시 모니터링
인증키 없이 실시간으로 열리는 데이터로 정기적으로 편차를 점검하는 체계 구축
