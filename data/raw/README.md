이 폴더의 CSV는 AI가 NEIS 나이스 교육정보 개방포털 API(open.neis.go.kr, 인증키 불필요)를 실제로 호출해서 받은 값을 그대로 정리한 것입니다. 추측이나 예시가 아니라 실측치입니다.

- `급식_표본데이터_20260504-20260529.csv` — 부산 6개교(초2·중2·고2, 서로 다른 구·군) × 2026년 5월 4주차 평일 5일치 중식 급식 원자료(칼로리·탄단지·튀김/면류 태깅)
- `학교급별_칼로리_요약.csv` — 위 원자료를 학교급별로 평균 낸 요약표
- `요일별_튀김면류_등장비율.csv` — 요일별로 튀김/면류 메뉴가 나온 학교 비율

## 더 채우고 싶다면 (주중 작업)

같은 방식으로 다른 학교·다른 주(week)를 추가할 수 있습니다. 브라우저 주소창에 아래 형식으로 입력하면 바로 JSON이 보입니다(가입/인증키 불필요):

```
https://open.neis.go.kr/hub/mealServiceDietInfo?Type=json&ATPT_OFCDC_SC_CODE=C10&SD_SCHUL_CODE=학교코드&MMEAL_SC_CODE=2&MLSV_FROM_YMD=YYYYMMDD&MLSV_TO_YMD=YYYYMMDD&pSize=100
```

학교코드는 `hub/schoolInfo?Type=json&ATPT_OFCDC_SC_CODE=C10&SCHUL_KND_SC_NM=중학교` 형태로 조회하면 찾을 수 있습니다(주소·학교급 포함).
