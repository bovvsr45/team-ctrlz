**왜 이 데이터를 골랐는가**: 지난 시도(1인가구·CCTV)에서는 데이터가 존재해도 다운로드 버튼이 자바스크립트로 동작해 자동 조사로는 실제 파일을 받지 못하는 문제가 있었습니다. NEIS 개방포털은 인증키 없이 URL만으로 즉시 JSON 응답을 주기 때문에, 이번에는 AI가 실제로 데이터를 받아 계산까지 전부 마칠 수 있었습니다.

## 표본 수집 범위

- 학교 6곳(부산진구·기장군·강서구·남구·사하구·서구 — 서로 다른 6개 구·군), 학교급별 2곳씩(초·중·고)
- 기간: 2026년 5월 4~5주차 평일 5일(중식만)
- 원자료: `data/급식_표본데이터_20260504-20260529.csv`

## 환각 검문소

- 모든 수치는 AI가 위 API를 직접 호출해 받은 JSON 원문에서 그대로 옮긴 것입니다(추정치 없음).
- 다만 표본이 6개교·5일뿐이라 "부산 전체"로 일반화하기엔 이릅니다 — 한계로 report에 기록했습니다.
- 급식 API 응답에는 "해당 자료는 단순 참고용으로만 활용하시기 바랍니다"라는 안내가 포함되어 있어, 실제 급식 운영 판단에는 학교 공지사항과 함께 봐야 합니다.
